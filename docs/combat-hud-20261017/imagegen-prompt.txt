Use case: stylized-concept.
Asset type: ONE production sprite atlas for a mobile auto-battler combat HUD, 5 columns by 4 rows, 20 distinct icons, transparent background.
Create polished, charming, exceptionally readable small status-effect icons inspired by the simplicity of Clash Mini combat HUD symbols. The game will display each glyph inside a tiny 18 pixel colored circular badge. The icon should be a large, bold, soft cartoon silhouette with smooth anti-aliased edges, a chunky clean shape, subtle pale-gray shading and a very narrow dark-blue contour. Most icons are ivory-white. NOT pixel art, not jagged geometry, not fine detailed illustrations, no realistic metallic textures. Think professionally painted mobile game UI glyphs. Maintain a consistent clean visual family. Each icon occupies 70% of its equal square cell and is precisely centered.
Layout: exact regular 5-column x 4-row grid. No visible grid, no cell backgrounds, no labels, no text, no digits, no buttons, no circular badges, no timers, no bars. Transparent space separates every icon. All cells the same size. Nothing may touch another cell. Orthographic front view.
