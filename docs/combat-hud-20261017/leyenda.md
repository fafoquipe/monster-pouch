# Qué significa cada icono

En combate cada símbolo aparece dentro de un círculo con fondo opaco. El aro exterior indica el tiempo restante; el centro no se vuelve transparente. Los efectos permanentes conservan el aro completo. El contador de ataques mantiene su borde blanco y brilla cuando el siguiente golpe activa la pasiva.

Esta es la leyenda del atlas, de izquierda a derecha y de arriba abajo:

| Símbolo | Significado |
| --- | --- |
| Espada, sobre círculo rojo | Daño aumentado o próximo golpe potenciado. Sin porcentajes. |
| Dos espadas con estelas azules | Más velocidad de ataque. |
| Fantasma | Invisibilidad. |
| Escudo sencillo | Reducción del daño recibido, incluida la protección de Bugaloo. |
| Escudo dentro de una burbuja | Escudo que absorbe daño antes de perder vida. |
| Estrella de cinco puntas amarilla | Aturdimiento. |
| Rayo amarillo | Aturdimiento eléctrico. No representa debilidad. |
| Botas pegadas al chicle | Inmovilización: no puede desplazarse. |
| Espada con flecha hacia abajo | Menor velocidad de ataque. |
| Luna amarilla con estrellita azul | Sueño. |
| Llama | Quemadura: daño periódico. |
| Corazón tachado | Curación recibida reducida. |
| Escudo roto lila | Vulnerabilidad: recibe más daño. |
| Bocadillo con exclamación | Provocación: obliga a atacar a quien la aplica. |
| Dos flechas curvas | Reflejo: devuelve daño al atacante. |
| Rombo amarillo de cuatro puntas | Inmunidad al control, como la mejora de Atong. No evita el daño. |
| Bola completamente blanca sobre gris | Invulnerabilidad: no puede recibir daño, como la flor de Flo. En el juego el centro se dibuja blanco plano. |
| Roca | Pasiva de Trimol al iniciar/reiniciar su contador. |
| Gancho | Pasiva de barrido de Popow, o arrastre cuando aparece como estado con duración. |
| Chocolate | Efecto de chocolate de Tsu: daño progresivo durante la inmovilización. |

Los iconos solo aparecen cuando el estado o la mejora correspondiente existe en el combate. La roca identifica una pasiva; no añade un estado nuevo. Tampoco se ha añadido la pasiva de invisibilidad del Fantasma Real: se tomó como referencia visual para mostrar las pasivas que ya tiene este juego.
