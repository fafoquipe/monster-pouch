# September 14 character design import

Original source files are preserved. Only border-connected background pixels are removed in RGBA derivatives. Sprite rectangles and GUID references are assigned through the Unity Editor API.

Existing battle animations, reference scale and foot anchors are retained. Newly added characters use the existing runtime breathing, walking bob, attack anticipation/contact and death-collapse animation of their supplied frontal sprite; these are not authored directional animation sheets.
